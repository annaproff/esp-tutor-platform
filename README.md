🎓 AI-ассистент преподавателя

Открытый проект интерактивного AI-ассистента для преподавателей английского языка (мой пример ESP, но вы адаптируете под свой контекст).

🚀 О проекте

Данная обвязка (harness) позволяет превратить интерактивные задания для отработки с LLM по вашим сценариям в систему, которая автоматически оценивает ответы, защищает результаты от подделки и формирует отчеты для преподавателя.

🛠 Как использовать

1. Скопируйте этот репозиторий (Fork).
2. Отредактируйте файлы в папке `tasks/`, добавив свои задания и критерии оценки (можно генерить с любой LLM по примеру моих файлов).
3. Настройте переменные окружения (API ключи, у меня YandexGPT; и базу данных SQL, у меня supabase).
И можно деплоить (у меня timeweb). Все делается вайбкодингом с любой моделькой (мне помогал qwen). 

📂 Структура

- `tasks/` — здесь лежат сценарии ваших уроков в формате YAML.
- `requirements.txt` — необходимые библиотеки Python.
