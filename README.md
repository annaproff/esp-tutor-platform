🎓 AI Tutor Platform

Открытый проект интерактивного AI-тьютора для преподавателей английского языка (мой пример ESP, но вы адаптируете под свой контекст).

🚀 О проекте

Этот харнесс позволяет превратить текстовые сценарии уроков (в формате YAML) в интерактивные диалоги со студентами. Система автоматически оценивает ответы, защищает результаты от подделки и формирует отчеты для преподавателя.

🛠 Как использовать

1. Скопируйте этот репозиторий (Fork).
2. Отредактируйте файлы в папке `tasks/`, добавив свои вопросы и рубрики оценки.
3. Настройте переменные окружения (API ключи YandexGPT и базу данных).
4. Задеплойте на Streamlit Cloud или Render.

📂 Структура

- `tasks/` — здесь лежат сценарии ваших уроков в формате YAML.
- `requirements.txt` — необходимые библиотеки Python.
